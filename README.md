# Estruturas de Dados em C

Repositório desenvolvido para **estudo e prática de Estruturas de Dados utilizando a linguagem C**.

O objetivo deste projeto é implementar e compreender, na prática, diferentes estruturas de dados, explorando conceitos como ponteiros, structs, alocação dinâmica de memória, manipulação de vetores e organização de dados.

## Conceitos estudados

Durante o desenvolvimento deste projeto, são praticados conceitos fundamentais da linguagem C e de Estruturas de Dados, incluindo:

- Structs
- Ponteiros
- Ponteiros para structs
- Vetores
- Strings
- Alocação dinâmica de memória
- `malloc()` e `free()`
- Manipulação de memória
- Estruturas sequenciais
- Estruturas encadeadas
- Listas circulares
- Pilhas
- Filas
- Deques
- LIFO (Last In, First Out)
- FIFO (First In, First Out)
- Overflow e Underflow
- Separação entre arquivos `.h` e `.c`
- Compilação utilizando GCC
